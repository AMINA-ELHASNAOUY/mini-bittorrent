# Mini BitTorrent Client

A BitTorrent client built from scratch in Go — no external torrent libraries.

## Why
Most portfolios have a todo app. This has peer discovery, chunked file transfer, and raw peer-to-peer networking — no central server.

## Status
🚧 In progress — building milestone by milestone.

## Milestones
- [ ] Bencode parser
- [ ] Torrent file parser
- [ ] Tracker client
- [ ] Peer wire protocol
- [ ] Piece downloader
- [ ] Multi-peer download

## Stack
Go, standard library only where possible.
